## Automated Coverage

The existing tests exercise:

- Deck composition, card effects, draw stacking, and ordinary single-card draws.
- Forced play of a playable drawn card and hand-swap target selection.
- The 36-card elimination threshold, finish order, configurable round endings, and tied rankings.
- Randomized complete games and card-identity/conservation checks during ordinary play.
- Local TCP gameplay, reconnect behavior, private hand snapshots, and host-only room actions.
- UNO declarations, missed-call penalties, and event synchronization.
- Color-wheel geometry, roulette reveals, animation waits, and rendering commands.
- Author-mode play, card generation, unique generated identifiers, and ordinary-player restrictions.
- Central penalty acceptance and drawing through the right-hand draw pile.

## Manual Verification Still Needed

- Windows desktop appearance and transparent overlay behavior.
- Mouse dragging, keyboard shortcuts, and animation timing on physical desktops.
- Cross-device LAN play over an actual Wi-Fi or wired network.
- Platform-specific appearance on macOS and Linux.

Rendering-command tests verify drawing logic but do not assess visual appearance. Local TCP tests run on one machine and do not exercise router configuration or real network isolation.
